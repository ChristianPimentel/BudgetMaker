# **App Name**: Receipt Wrangler

## Core Features:

- Receipt Input: Allow users to upload receipt images or manually enter receipt details, including date, amount, and category.
- Receipt Autocategorization: Use an AI tool to attempt to automatically categorize receipts based on the vendor name.
- Budget Creation: Allow the user to create a monthly budget, broken down by category.
- Budget Comparison: Display a comparison of spending vs. budget for each category, including visual elements to indicate how much budget remains.
- Receipt List: Display a list of all entered receipts, sortable by date, amount, or category.

## Style Guidelines:

- Primary color: Sky blue (#77B5FE), conveying trust and organization, reflecting financial clarity.
- Background color: Light gray (#F0F0F0), for a clean, neutral backdrop that won't distract from the data.
- Accent color: Soft green (#AEC6CF) to highlight positive budget variances (underspending), and help make the user feel calm about their financial position.
- Font pairing: 'Inter' sans-serif for body and headlines for a modern and clean interface.
- Use simple, minimalist icons for receipt categories and budget sections.
- Keep the layout clean and uncluttered, focusing on data clarity and ease of use.
- Use subtle animations for transitions and data updates to enhance user engagement without being distracting.
